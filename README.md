# LEOBOG HI75C Studio

## Что нужно
- Python 3
- Три файла в одной папке: `app.py`, `run.sh`, `README.md`

## Установка
```bash
chmod +x run.sh
./run.sh
```
Скрипт сам создаст `venv`, поставит зависимости и запустит программу.
Зависимости (ставятся автоматически, ничего вписывать не нужно):
```
pyusb
customtkinter
pystray
pillow
evdev
```

Если раньше уже запускал и `venv` уже есть — удали его один раз и запусти
заново (нужно для трея, см. ниже):
```bash
rm -rf venv
./run.sh
```

## Как пользоваться
Просто запускай `./run.sh` каждый раз — venv уже готов, повторно ничего
не ставится, программа открывается сразу.

## Автозапуск при входе в систему

Программа запоминает последний выбранный режим, цвет, яркость, скорость,
ось и направление (файл `~/.config/leobog-hi75c-studio/state.json`) и
применяет их сразу при следующем запуске — ничего настраивать заново не
нужно.

Чтобы при автозапуске **не открывалось окно** каждый раз при входе в
систему, используй флаг `--tray`: программа сразу свернётся в трей (или
просто в фон, если трея нет) и включит свет с последними настройками.

**Hyprland** — добавь строку в `~/.config/hypr/hyprland.conf`:
```
exec-once = /путь/до/папки/run.sh --tray
```
(вместо `/путь/до/папки/` впиши реальный путь, где лежат файлы)

**Другие DE (GNOME/KDE/...)** — добавь команду `/путь/до/папки/run.sh --tray`
в приложения автозагрузки (Startup Applications).

Открыть окно настроек после такого автозапуска можно через иконку в трее
(если она есть — см. ниже) — пункт «Открыть настройки». Если трея нет,
запусти `./run.sh` (без `--tray`) вручную ещё раз: программа увидит уже
работающий процесс и предложит закрыть его и перезапуститься с окном.

## Чтобы в Hyprland появилась иконка в трее

Hyprland сам трей не рисует — его показывает бар (waybar и т.п.), а python
нужен рабочий AppIndicator-бэкенд. Нужны ДВА условия одновременно:

**1. Системные пакеты (не через pip, ставятся один раз через менеджер пакетов):**

Arch:
```bash
sudo pacman -S libayatana-appindicator python-gobject
```
Ubuntu/Debian:
```bash
sudo apt install gir1.2-ayatanaappindicator3-0.1 python3-gi
```

**2. Модуль трея в баре.** Для waybar — в `~/.config/waybar/config` добавь
`"tray"` в список модулей и блок настроек:
```json
"modules-right": ["tray", "clock"],
"tray": {
    "icon-size": 18,
    "spacing": 8
}
```
Перезапусти waybar. Если используешь другой бар (ironbar, eww, ags) — там
тоже должен быть отдельный модуль/виджет трея, без него иконка не появится
в принципе, вне зависимости от программы.

После установки пакетов удали `venv` и запусти `run.sh` заново (см. выше) —
venv должен видеть системные пакеты. При запуске в консоли будет строка
`[ТРЕЙ] Бэкенд pystray: ...` — если там не `appindicator`, значит пакеты
из пункта 1 не установлены или venv их не видит.

## Если роллер / mute не реагируют
```bash
sudo usermod -aG input $USER
```
и перелогинься (или перезагрузись).

## Режим «Реакция на нажатие»
Этот режим уже слушает клавиатуру системно, через `evdev` (`/dev/input`),
а не только пока окно программы в фокусе — то есть реагирует на нажатия
в любом приложении. Чтобы это заработало без root, аккаунт должен быть в
группе `input` (см. пункт выше про `usermod -aG input`) — без этого
`evdev` не даст программе читать `/dev/input`, и режим упадёт в резервный
режим со случайными кольцами (в консоли будет пометка `[РЕАКЦИЯ]`).
Если нужного устройства не нашлось по VID/PID, программа сама пробует
любые клавиатуроподобные устройства — какая клавиатура реально слушается,
тоже видно в консоли.
