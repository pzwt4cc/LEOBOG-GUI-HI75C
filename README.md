# LEOBOG HI75C Studio

Программа для управления RGB-подсветкой клавиатуры **LEOBOG HI75C** на Linux:
режимы, цвета, скорость, яркость и эффекты «от нажатия клавиши». Без драйверов
производителя, всё работает через `hidraw`.

![Окно программы](screenshot.png)

## Возможности

- **13 режимов подсветки:** сплошной цвет, дыхание, радуга, цветопереход, волна,
  змейка, двойная змейка, комета, рябь, мерцание и три режима «от нажатия».
- **Режимы от нажатия клавиши**
  - _Реакция на нажатие_ — свет разливается от клавиши во все стороны и тускнеет с расстоянием.
  - _Кольцо от нажатия_ — тонкое кольцо бежит от клавиши до самого края клавиатуры, позади него света нет.
  - _Ряд в обе стороны_ — свет бежит от клавиши по её ряду вправо и влево.
- **Живое превью** клавиатуры в окне. Клик по клавише в превью работает как нажатие,
  так можно пробовать эффекты, не трогая настоящую клавиатуру.
- **Цвет:** круг, поля R/G/B и готовые цвета.
- **Яркость и скорость:** свободный ползунок и быстрые кнопки.
  Яркость: 0 / 25 / 50 / 75 / 100 %. Скорость: 25 / 50 / 100 / 200 / 400 %.
- **Траектория:** вправо, влево, вниз, вверх. Один клик задаёт ось и направление.
- **Запоминает настройки** и применяет их при следующем запуске.
- **Трей и автозапуск** (флаг `--tray`).

## Установка

Нужен Python 3 с Tkinter (в Debian/Ubuntu: `sudo apt install python3-tk`).
Три файла положите в одну папку: `app.py`, `run.sh`, `README.md`.

```bash
chmod +x run.sh
./run.sh
```

Скрипт сам создаст `venv` и поставит зависимости (`pyusb`, `customtkinter`, `pystray`,
`pillow`, `evdev`). Дальше просто запускайте `./run.sh`.

## Один раз настроить права

Чтобы программа могла работать без root, нужны два пункта.

**1. Доступ к клавиатуре (hidraw).** Подсветка отправляется через `/dev/hidraw`
и при этом **не отключает драйвер клавиатуры**, поэтому колёсико громкости и
медиаклавиши продолжают работать.

```bash
echo 'KERNEL=="hidraw*", ATTRS{idVendor}=="258a", ATTRS{idProduct}=="010c", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-leobog.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

Переподключите клавиатуру. В консоли при запуске должна появиться строка
`[USB] Подключено через /dev/hidrawN`.

**2. Чтение нажатий (для режимов «от нажатия»).** Нужна группа `input`:

```bash
sudo usermod -aG input $USER
```

После этого перелогиньтесь. Без этого эффекты от нажатия работают только пока
окно программы в фокусе.

## Автозапуск

Программа сама запоминает последние настройки. Чтобы при входе в систему она
стартовала без окна, используйте флаг `--tray`.

**Hyprland**, строка в `~/.config/hypr/hyprland.conf`:

```
exec-once = /путь/до/папки/run.sh --tray
```

**GNOME / KDE и другие:** добавьте `/путь/до/папки/run.sh --tray` в автозагрузку.

Если трея нет, запустите `./run.sh` ещё раз без флага. Программа увидит уже
работающий экземпляр и предложит закрыть его и открыть окно.

### Иконка в трее (Hyprland / Wayland)

Трей рисует не программа, а панель, поэтому нужны два условия:

1. Системные пакеты (не через pip).
   Arch: `sudo pacman -S libayatana-appindicator python-gobject`.
   Debian/Ubuntu: `sudo apt install gir1.2-ayatanaappindicator3-0.1 python3-gi`.
2. Модуль трея в панели. Для waybar добавьте `"tray"` в `modules-right`.

После установки пакетов удалите `venv` и запустите `./run.sh` заново. В консоли
должна быть строка `[ТРЕЙ] Бэкенд pystray: appindicator`. Если трей недоступен,
кнопка «—» просто сворачивает окно.

## Карта клавиш

Расположение светодиодов под клавишами встроено в `app.py` (`DEFAULT_KEYMAP`).
На LEOBOG HI75C ничего калибровать не нужно, всё работает сразу. Светодиоды идут
по колонкам, по 6 в колонке.

Если у вас другая ревизия клавиатуры или какая-то клавиша попала не туда:

```bash
./run.sh --calibrate   # один раз: зажигается один светодиод, нажмите клавишу над ним
./run.sh --keytest     # диагностика: с какого устройства приходят нажатия
```

Перед калибровкой закройте программу. Результат сохраняется в
`~/.config/leobog-hi75c-studio/keymap.json`, дополняет встроенную карту и
имеет приоритет над ней.

## Если что-то не работает

| Проблема                                   | Что делать                                                                                                                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Нет строки `Подключено через /dev/hidrawN` | Проверьте правило udev и переподключите клавиатуру.                                                                                                                        |
| Не работает колёсико громкости             | Убедитесь, что программа подключилась через hidraw (см. выше). Старые версии отключали драйвер клавиатуры, помогает переподключение USB.                                   |
| Режимы «от нажатия» не реагируют вне окна  | Нужна группа `input` (`sudo usermod -aG input $USER`) и перелогин.                                                                                                         |
| Нажатия не приходят даже с группой `input` | Запустите `./run.sh --keytest`. Если нажатия идут с виртуального устройства (например, у записи экрана или remap-утилит), это нормально: программа слушает все клавиатуры. |
| Клавиша светится не там                    | Запустите `./run.sh --calibrate`.                                                                                                                                          |
| Нет иконки в трее                          | См. раздел про трей выше.                                                                                                                                                  |

## Файлы
